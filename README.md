# 💰 CashTrack

![CashTrack Banner](cashtrack_banner_1768215796600.png)

> **CashTrack** — это профессиональный Telegram-бот для глубокого контроля личных финансов. Спроектирован для тех, кто хочет перестать тратить деньги впустую и начать эффективно копить на свои цели.

---

## 🔥 Ключевые возможности

### 📊 Учёт и Аналитика
- **Транзакции в 2 клика**: Быстрый ввод доходов и расходов с категориями и описанием.
- **Умная статистика**: Интерактивные отчеты за неделю, месяц или всё время. Топ категорий и динамика трат.
- **Поддержка эмоций**: Отметка "импульсивных" покупок для последующего анализа "нужных" и "лишних" трат.

### 🎯 Планирование
- **Цели накопления**: Создавайте цели, отслеживайте прогресс с красивыми progress-bar-ами и достигайте мечты.
- **Бюджетные лимиты**: Устанавливайте ограничения на категории. Бот предупредит при достижении 50%, 80% и заблокирует транзакции при 100%.

### 🔄 Регулярность и Долги
- **Регулярные платежи**: Учёт подписок (интернет, аренда, Netflix). Поддержка **Фиксированного** (строгий график) и **Плавающего** (цикл от даты оплаты) типов.
- **Менеджер долгов**: Контроль того, кто должен вам и кому должны вы. Частичные возвраты и напоминания.

### 🤖 Личность и Уведомления
- **Персональный ассистент**: Бот общается в стиле "строгого тренера" или "дружелюбного помощника".
- **Гибкие напоминания**: Настраиваемое время утренних брифингов и вечерних отчетов.

## 🚀 Быстрый старт (Development)

### 1. Подготовка
Убедитесь, что у вас установлен **.NET 8 SDK** и запущен **PostgreSQL**.

### 2. Конфигурация
Создайте или отредактируйте `Console/appsettings.json`:
```json
{
  "BotToken": "ВАШ_ТЕЛЕГРАМ_ТОКЕН",
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Database=cashtrack_db;Username=postgres;Password=your_password"
  }
}
```

### 3. База данных
Примените миграции для создания структуры:
```bash
dotnet ef database update --project Infrastructure --startup-project Console
```

### 4. Запуск
```bash
dotnet run --project Console
```

## 📁 Структура проекта

- **Domain**: Ядро системы. Сущности (`User`, `Transaction`, `Goal`) и перечисления.
- **Infrastructure**: Реализация бизнес-логики. Сервисы для работы с БД, миграции и DataContext.
- **Console**: Точка входа. Обработчики команд Телеграма (`Commands`), клавиатуры (`Keyboards`) и логика диалогов (`Flow`).
